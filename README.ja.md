# Cybertruck Madness '98

Three.js で構築された実験的なオープンワールド・ブラウザ運転ゲームです。90年代後半のPCドライビングゲームが持っていた、混沌とした自由さにインスパイアされています。

**プレイ：** https://cybertruckmadness.vercel.app

> このリポジトリは公開されており、より広いコミュニティからの貢献を受け入れる準備を進めています。完全なオープンソースプロジェクトと表現する前に、ソフトウェアライセンスと第三者アセットの権利を確認中です。

## これは何か

Cybertruck Madness '98 では、大規模なプロシージャル地形を走り、ドリフトし、リングを集め、バッテリーを管理し、コンパス/マップで移動しながら、最終的に脱出目標をアンロックします。

現在のビルドには以下が含まれます：

- Three.js レンダリング
- 大規模なプロシージャル地形
- アーケード風の運転・ドリフト物理
- Cybertruck 3D 車両
- 500個の収集リング
- バッテリー / 充電メカニクス
- コンパスナビゲーション
- 展開可能なマップ
- キーボード操作
- モバイル向けタッチ操作
- カメラ切り替え
- エンジン、スキッド、収集、着地のオーディオ
- 脱出 / ミッション完了目標

## 操作

### デスクトップ

- `W` / `Arrow Up` — 加速
- `S` / `Arrow Down` — 後退
- `A` / `Arrow Left` — 左へ曲がる
- `D` / `Arrow Right` — 右へ曲がる
- `Space` — ブレーキ / ドリフト
- HUD ボタンでマップ、カメラ、音楽、SFX を操作

### モバイル

- 左側タッチゾーン — 移動・ステアリング
- 右側タッチゾーン — 長押しでブレーキ / ドリフト
- HUD ボタンでマップ、カメラ、音楽、SFX を操作

## ローカルで実行

このプロジェクトは ES modules とブラウザから読み込むアセットを使用するため、`index.html` を直接開くのではなく、ローカルWebサーバーから実行してください。

例：

```bash
python -m http.server 8000
```

その後、以下を開きます：

```text
http://localhost:8000
```

現在ビルドステップは不要です。
