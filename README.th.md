# Cybertruck Madness '98

[English](Readme.md)

เกมขับรถโอเพนเวิลด์เชิงทดลองบนเบราว์เซอร์ สร้างด้วย Three.js และได้แรงบันดาลใจจากความวุ่นวายและอิสระของเกมขับรถบน PC ช่วงปลายยุค 90

**เล่นเลย:** https://cybertruckmadness.vercel.app

> รีโพซิทอรีนี้เปิดสาธารณะและกำลังเตรียมพร้อมสำหรับการมีส่วนร่วมจากชุมชนในวงกว้างขึ้น โดยยังอยู่ระหว่างตรวจสอบสิทธิ์ด้านไลเซนส์ซอฟต์แวร์และทรัพย์สินของบุคคลที่สามก่อนจะเรียกโครงการนี้ว่าโอเพนซอร์สอย่างเต็มรูปแบบ

## มันคืออะไร

Cybertruck Madness '98 พาคุณเข้าสู่ภูมิประเทศแบบ procedural ขนาดใหญ่ ที่คุณสามารถขับ ดริฟต์ เก็บวงแหวน จัดการแบตเตอรี่ นำทางด้วยเข็มทิศ/แผนที่ และปลดล็อกเป้าหมายการออกจากพื้นที่

บิลด์ปัจจุบันมี:

- การเรนเดอร์ด้วย Three.js
- ภูมิประเทศ procedural ขนาดใหญ่
- ฟิสิกส์การขับและดริฟต์แบบอาร์เคด
- รถ Cybertruck 3D
- วงแหวนสะสม 500 วง
- ระบบแบตเตอรี่ / ชาร์จ
- การนำทางด้วยเข็มทิศ
- แผนที่แบบขยายได้
- การควบคุมด้วยคีย์บอร์ด
- การควบคุมแบบสัมผัสบนมือถือ
- การสลับกล้อง
- เสียงเครื่องยนต์ ลื่นไถล เก็บไอเท็ม และลงพื้น
- เป้าหมายออกจากพื้นที่ / จบภารกิจ

## การควบคุม

### เดสก์ท็อป

- `W` / `Arrow Up`: เร่ง
- `S` / `Arrow Down`: ถอยหลัง
- `A` / `Arrow Left`: เลี้ยวซ้าย
- `D` / `Arrow Right`: เลี้ยวขวา
- `Space`: เบรก / ดริฟต์
- ใช้ปุ่ม HUD สำหรับแผนที่ กล้อง เพลง และ SFX

### มือถือ

- โซนสัมผัสด้านซ้าย: เคลื่อนที่และบังคับเลี้ยว
- โซนสัมผัสด้านขวา: กดค้างเพื่อเบรก / ดริฟต์
- ปุ่ม HUD ใช้ควบคุมแผนที่ กล้อง เพลง และ SFX

## สถาปัตยกรรมปัจจุบัน

ตอนนี้โครงการตั้งใจให้เรียบง่าย:

```text
.
├── Readme.md
├── index.html
├── fbx/
│   ├── cybertruck.glb
│   └── moto.fbx
└── music/
```

ลอจิกเกมส่วนใหญ่ยังอยู่ใน `index.html` ทำให้ตรวจสอบได้ง่าย แต่ก็เป็นโอกาสสำหรับผู้ร่วมพัฒนาอย่างชัดเจนในการค่อย ๆ แยกระบบเป็นโมดูลโดยไม่เปลี่ยนพฤติกรรมการเล่น

## รันในเครื่อง

โครงการใช้ ES modules และโหลดแอสเซ็ตผ่านเบราว์เซอร์ จึงควรรันผ่านเว็บเซิร์ฟเวอร์ในเครื่องแทนการเปิด `index.html` โดยตรง

ตัวอย่าง:

```bash
python -m http.server 8000
```

จากนั้นเปิด:

```text
http://localhost:8000
```

ตอนนี้ยังไม่ต้องมีขั้นตอน build
