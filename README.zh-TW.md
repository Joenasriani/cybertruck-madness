# Cybertruck Madness '98

一款使用 Three.js 製作的實驗性開放世界瀏覽器駕駛遊戲，靈感來自 90 年代末 PC 駕駛遊戲那種混亂又自由的感覺。

**立即遊玩：** https://cybertruckmadness.vercel.app

> 本儲存庫為公開專案，目前正積極準備讓更廣泛的社群參與貢獻。原始碼採 MIT 授權；隨附 3D/音訊資產的權利在 `ASSETS.md` 中分開記錄，目前仍在確認。

## 這是什麼

Cybertruck Madness '98 會把你放進一大片程序化地形中。你可以駕駛、甩尾、收集圓環、管理電量，透過指南針/地圖導航，並最終解鎖撤離目標。

目前版本包含：

- Three.js 渲染
- 大型程序化地形
- 街機式駕駛與甩尾物理
- Cybertruck 3D 車輛
- 500 個可收集圓環
- 電池 / 充電機制
- 指南針導航
- 可展開地圖
- 鍵盤控制
- 行動裝置觸控
- 鏡頭切換
- 引擎、甩尾、收集與落地音效
- 撤離 / 任務完成目標

## 操作

### 桌面

- `W` / `Arrow Up`: 加速
- `S` / `Arrow Down`: 倒車
- `A` / `Arrow Left`: 左轉
- `D` / `Arrow Right`: 右轉
- `Space`: 煞車 / 甩尾
- 使用 HUD 按鈕控制地圖、鏡頭、音樂與 SFX

### 行動裝置

- 左側觸控區: 移動與轉向
- 右側觸控區: 按住進行煞車 / 甩尾
- HUD 按鈕控制地圖、鏡頭、音樂與 SFX

## 目前架構

專案目前刻意保持簡單：

```text
.
├── Readme.md
├── index.html
├── fbx/
│   ├── cybertruck.glb
│   └── moto.fbx
└── music/
```

大部分遊戲邏輯目前都位於 `index.html`。這讓專案容易檢視，同時也形成了明確的貢獻機會：在不改變現有可玩行為的前提下，逐步把系統模組化。

## 本機執行

專案使用 ES modules 與瀏覽器載入的資產，因此請透過本機 Web 伺服器執行，而不是直接開啟 `index.html`。

例如：

```bash
python -m http.server 8000
```

接著開啟：

```text
http://localhost:8000
```

目前不需要建置步驟。

## 貢獻理念

這個專案應該保持可玩、實驗性，並帶一點奇怪。

目標不是把它變成通用框架。貢獻應該讓遊戲更有趣、更具技術價值、更容易擴充，或更容易執行。
