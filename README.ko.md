# Cybertruck Madness '98

[English](Readme.md)

Three.js로 만든 실험적인 오픈월드 브라우저 드라이빙 게임입니다. 1990년대 후반 PC 드라이빙 게임 특유의 혼란스럽고 자유로운 감성에서 영감을 받았습니다.

**플레이:** https://cybertruckmadness.vercel.app

> 이 저장소는 공개되어 있으며 더 넓은 커뮤니티의 기여를 받을 수 있도록 준비 중입니다. 프로젝트를 완전한 오픈소스로 설명하기 전에 소프트웨어 라이선스와 제3자 에셋 권리를 확인하고 있습니다.

## 무엇인가요

Cybertruck Madness '98에서는 대규모 절차적 지형을 달리고, 드리프트하고, 링을 수집하고, 배터리를 관리하며, 나침반/지도로 탐색한 뒤 탈출 목표를 해제합니다.

현재 빌드에는 다음이 포함됩니다:

- Three.js 렌더링
- 대규모 절차적 지형
- 아케이드 스타일 운전 및 드리프트 물리
- Cybertruck 3D 차량
- 수집 가능한 링 500개
- 배터리 / 충전 메커니즘
- 나침반 내비게이션
- 확장형 지도
- 키보드 조작
- 모바일 터치 조작
- 카메라 전환
- 엔진, 스키드, 수집, 착지 오디오
- 탈출 / 미션 완료 목표

## 조작

### 데스크톱

- `W` / `Arrow Up`: 가속
- `S` / `Arrow Down`: 후진
- `A` / `Arrow Left`: 왼쪽 조향
- `D` / `Arrow Right`: 오른쪽 조향
- `Space`: 브레이크 / 드리프트
- HUD 버튼으로 지도, 카메라, 음악, SFX 제어

### 모바일

- 왼쪽 터치 영역: 이동 및 조향
- 오른쪽 터치 영역: 길게 눌러 브레이크 / 드리프트
- HUD 버튼으로 지도, 카메라, 음악, SFX 제어

## 현재 아키텍처

현재 프로젝트는 의도적으로 단순하게 유지하고 있습니다:

```text
.
├── Readme.md
├── index.html
├── fbx/
│   ├── cybertruck.glb
│   └── moto.fbx
└── music/
```

현재 대부분의 게임 로직은 `index.html`에 있습니다. 덕분에 살펴보기 쉽지만, 플레이 동작을 바꾸지 않고 시스템을 점진적으로 모듈화할 수 있는 명확한 기여 기회이기도 합니다.

## 로컬 실행

이 프로젝트는 ES modules와 브라우저에서 로드되는 에셋을 사용하므로 `index.html`을 직접 여는 대신 로컬 웹 서버에서 실행하세요.

예:

```bash
python -m http.server 8000
```

그다음 열기:

```text
http://localhost:8000
```

현재는 빌드 단계가 필요하지 않습니다.

## 기여 철학

이 프로젝트는 플레이 가능하고, 실험적이며, 약간은 이상한 상태를 유지해야 합니다.

목표는 범용 프레임워크로 만드는 것이 아닙니다. 게임을 더 재미있고, 기술적으로 흥미롭고, 확장하기 쉽고, 실행하기 쉽게 만드는 기여를 환영합니다.

거대한 재작성보다 작고 집중된 Pull Request를 선호합니다.
